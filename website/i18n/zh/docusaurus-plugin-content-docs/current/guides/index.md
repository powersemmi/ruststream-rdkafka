# 指南

`ruststream-rdkafka` 是 [RustStream](https://powersemmi.github.io/ruststream/latest/zh/) 的 Apache Kafka Broker，
基于 [rust-rdkafka](https://docs.rs/rdkafka) 和 librdkafka 构建。这些指南带你把一个 Kafka 服务从安装一路推进到生产环境。
