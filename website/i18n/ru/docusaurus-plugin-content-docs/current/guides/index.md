# Руководства

Крейт `ruststream-rdkafka` реализует брокер Apache Kafka для [RustStream](https://powersemmi.github.io/ruststream/latest/ru/).
Он построен на [rust-rdkafka](https://docs.rs/rdkafka) и librdkafka. Руководства проводят сервис
на Kafka от установки до промышленной эксплуатации.
Начните с руководства [Начало работы](getting-started.md).
