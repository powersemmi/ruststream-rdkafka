# Группы

Группа консьюмеров отдаёт каждую партицию одному участнику, а когда участник входит в группу или
выходит из неё, партиции переносятся при перебалансировке.

<Diagram name="groups" words={words} />

Координатор группы - один из брокеров кластера. Когда участник входит или выходит, координатор
начинает перебалансировку, и группа договаривается о новом назначении. Партиция, которую забрали у
одного участника, у него отзывается и назначается другому, а тот продолжает с зафиксированного
смещения группы. Работу, которую первый участник сделал после своей последней фиксации, второй
прочитает заново. Партиция, для которой группа ещё ничего не фиксировала, начинается там, где
велит [`auto.offset.reset`](../../components/subscriptions/start-offset.md): по умолчанию с конца журнала.

Участник, который не присылает контрольные сигналы дольше `session.timeout.ms` (45 секунд в librdkafka),
исключается из группы. Участник, который не берёт новую запись дольше `max.poll.interval.ms`
(5 минут), тоже выходит из группы.

[`partition.assignment.strategy`](../../components/subscriptions/assignment.md) решает, как перебалансировка переносит партиции. Жадные
стратегии, `range` и `roundrobin` (по умолчанию librdkafka берёт обе, `range` первой), отзывают
все партиции и назначают их заново. `cooperative-sticky` переносит только партиции, которые
меняют владельца, а остальные продолжают читаться во время перебалансировки
([KIP-429](https://cwiki.apache.org/confluence/display/KAFKA/KIP-429%3A+Kafka+Consumer+Incremental+Rebalance+Protocol)).
Внутри одной группы два семейства смешивать нельзя.

Консьюмер может [взять партиции и по имени](../../components/subscriptions/kafka-partitions.md), не вступая в протокол группы. Тогда перебалансировки у
него не бывает, и его партиции никуда не переносятся.

Значения по умолчанию взяты из librdkafka
([конфигурация](https://github.com/confluentinc/librdkafka/blob/v2.12.1/CONFIGURATION.md),
[группы консьюмеров](https://github.com/confluentinc/librdkafka/blob/v2.12.1/INTRODUCTION.md#consumer-groups)).
