# Путь

Путь одной записи Kafka через сервис RustStream: очередь выборки, доставка, обработчик, ответ и
фиксация.

<Diagram name="path" words={words} />

Запись, которую librdkafka уже выбрала, забирается без ожидания.
[`KafkaMessage`](api:ruststream_rdkafka::KafkaMessage) держит её там, куда её положила librdkafka,
вместе со счётчиком ссылок на консьюмер, которому принадлежит этот буфер. Тело, ключ и заголовки
читаются из буфера выборки без копирования, а заголовки преобразуются, только когда их кто-то
запрашивает. Консьюмер остаётся открытым, пока хоть одна доставка держит его запись.

Копируется только та запись, которую поток получает сам, дождавшись её: если очередь была пуста,
запись, которую вернуло ожидание, копируется наружу.

Ответ обработчика кодируется в буфер, который цикл диспетчеризации использует повторно. Издатель
одалживает эти байты librdkafka, она копирует их в свою очередь, и публикация возвращается, когда
кластер подтвердил запись. Если ответ не удалось опубликовать, доставка завершается повтором.

Доставка завершается после ответа. Что это значит для зафиксированного смещения, зависит от режима
[`Commit`](api:ruststream_rdkafka::Commit) подписки, который показывает страница
[Завершение](settlement.md).
