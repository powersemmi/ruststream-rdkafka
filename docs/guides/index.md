# Guides

`ruststream-rdkafka` is the Apache Kafka broker for [RustStream](https://powersemmi.github.io/ruststream/latest/),
built on [rust-rdkafka](https://docs.rs/rdkafka) and librdkafka. The guides take a Kafka service
from installation to production.
